## THE GOLDEN RULES (from LO, violated = pain)

1. NEVER run `adb shell su -c "long command; chain"` inline from PowerShell/cmd.
   Windows mangles quoting and SELinux context. ALWAYS:
   - write commands into a .sh file
   - `adb push script.sh /data/local/tmp/`
   - `adb shell su -c "sh /data/local/tmp/script.sh"`
   Files needing adb-pull access must be copied to /data/local/tmp first
   (app dirs are not adb-readable): `cat /src/file > /data/local/tmp/ilregs/file && chmod 644`.
2. frida CLI 17.9.1 API changes:
   - NativeFunction multi-arg `.call(a, b)` = BROKEN ("bad argument count").
     Call the function DIRECTLY: `fn(a, b)`.
   - `Module.findExportByName` removed. Use `Module.getExportByName` (throws if missing).
   - ArrayBuffer is NOT accepted as a pointer arg to NativeFunction.
   - `readCString()` returns a string already (no `.readUtf8String()` after it).
   - Il2Cpp System.String = {klass, monitor, int32 len @0x10, utf16 chars @0x14}.
     `readUtf8String` on it throws ("can't decode byte 0xfe") - decode UTF-16 manually.
   - NativePointers can be MTE/GC-tagged (0xb40000...). Tagged pointers from
     DataView.getBigUint64 MUST stay `ptr(val.toString())` — Number() is lossy.
3. frida REPL hangs when piped (exit not consumed when stdout is chained).
   Use: background (`start /b`), sleep, `taskkill /f /im frida.exe`. Never trust exit pipes in .cmd.

## METADATA FORMAT (Moonton v1024, validated 3/3 blobs)

- In-memory layout: [magic FAB11BAF][version 1024][fileIndex 1|2|3][headerSize 252]
  then 28 section pairs of (size, cumulativeEnd). offset_k = ints[3+2k], size_k = ints[4+2k].
- Section order == vanilla il2cpp v24.4. 28 sections = vanilla minus
  metadataUsageLists/Pairs, windowsRuntimeTypeNames, exportedTypeDefinitions.
- Disk files: encrypted wrapper 0x135BA1DA + payload len + key table + IV + "CODEPHIL" @+328,
  real header @+336. Decryptor fn @ liblogic+0xDDED2C, in place, 64B blocks.
- Cross-blob index encoding: (fileIndex << 24) | localIndex for strings/types/fields/etc.
  Plain-local form also exists (small values, own blob).
- `moba/meta/merge.py` produces a fully rebased vanilla-format global-metadata-merged.dat
  (28,908 typedefs, 241,674 types). Dumper v6.7.46 accepts it (metadata side COMPLETE).
- Binary registrations: blob1 = internal in liblogic (.data.rel.ro, file off 0x1998b40),
  blob2/3 = runtime structs passed to il2cpp_codegen_register_moba by libcsharp.
  typesCounts: blob1 31564, blob2 13764, blob3 196346. Merged table = concat blob order 1,2,3.
